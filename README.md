# baldibasicForGM

本项目使用 **GameMaker LTS 2026** 和 **GML** 制作，原作《Baldi's Basics v1.4.3》

原游戏由 **mm12（mystman12）** 使用 **Unity** 制作。本项目参考原游戏的 Unity 反编译工程，还原其场景、资源和玩法。

## 游玩方式

使用 GameMaker LTS 2026 打开 `baldibasicForGM.yyp`，点击运行或按 **F5** 启动游戏。在主菜单选择 **START**，再选择 **Story** 或 **Endless**。

- **Story**：收集 7 本笔记本并完成答题，然后寻找 4 个出口逃离学校。
- **Endless**：尽可能收集更多笔记本，挑战最高纪录。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD／方向键 |
| 转向 | 鼠标 |
| 跑步 | Shift |
| 开门、拾取物品或笔记本 | 鼠标左键 |
| 选择物品 | 1／2／3 或鼠标滚轮 |
| 使用物品 | 鼠标右键或 Q |
| 向后看／跳绳时跳跃 | 空格 |
| 暂停／继续 | Esc |
| 暂停时返回主菜单 | Q |
| 切换全屏 | F11 |
| 打开／关闭测试菜单 | F1 |
